---
title: "How to Add Mods to Your Vintage Story Server"
---

Vintage Story mods can be installed by uploading the mod file directly to your server. Once installed, players can automatically download the required mods when connecting.

## Step 1: Download the Mod

1. Visit [VSModDB](https://mods.vintagestory.at/list/mod).
2. Find the mod you want to install.
3. Download the version that matches your server's Vintage Story version.
4. Keep the downloaded mod as a `.zip` file.

## Step 2: Upload the Mod

1. Log in to the game panel at `gamepanel.fourseasonshosting.com`.
2. Select your Vintage Story server.
3. Stop the server before making changes.
4. Open the **Files** section.
5. Navigate to `data` and then open the `Mods` folder.
6. Upload the mod's `.zip` file into the `Mods` folder.

**Do not extract the ZIP file.** Vintage Story can load the mod directly from its ZIP archive.

## Step 3: Start the Server

Once the upload is complete, start your server.

When players connect, the server can provide the installed mods to them automatically.

### Important

Make sure the server and all players are using the same Vintage Story game version. Mods may also require a specific game version, so always check the mod's compatibility before installing it.
