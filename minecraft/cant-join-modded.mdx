---
title: "Can't Join A Minecraft Modded Server"
---

There are several reasons you might not be able to join a modded server. This guide covers the most common ones.

### Missing Forge or Fabric Mod Loader

If you get an error when joining, first check that you have a mod loader installed. Mods require Forge, NeoForge, Fabric, or Quilt to work, and the right one depends on your mods:

- Fabric mods can be loaded on Quilt or Fabric
- Forge mods can be loaded on Forge or NeoForge
- Quilt mods can only be loaded on Quilt
- NeoForge mods can only be loaded on NeoForge

Make sure both the server and your client run the correct loader for your mods.

### Missing Mods

The server and your client must have the same mods and configs. Mods on the server that aren't on the client or vice versa will stop you from joining.

### Timeout Issues

If the mods and configs match and you're running a mod loader but still get a connection or timeout error, a simple fix is to install the Connectivity mod on both the client and the server: \<[https://www.curseforge.com/minecraft/mc-mods/connectivity](https://www.curseforge.com/minecraft/mc-mods/connectivity)\>
