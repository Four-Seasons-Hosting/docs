---
title: "How to Adjust Minecraft Server Mob Spawn Rates"
---

You can control the maximum number of mobs that can spawn in different categories on your Minecraft server. Adjusting these limits can help increase or reduce the number of mobs present in your world.

This setting is available on servers running **Spigot, Paper, or Bukkit**.

## Changing Mob Spawn Limits

1. Log in to the game panel at `gamepanel.fourseasonshosting.com`.
2. Select **Files** from the server navigation.
3. Locate `bukkit.yml` in the main server directory and open it.
4. Look for the `spawn-limits` section. This contains the maximum spawn counts for different mob categories, such as monsters, animals, and water-based mobs.
5. Update the values according to your desired spawn limits.
6. Select **Save** to apply the changes to the configuration file.
7. Restart your Minecraft server.

The new spawn limits will be applied after the server starts back up.
