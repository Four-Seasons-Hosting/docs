---
title: "How To Enable Flight On A Minecraft Server"
---

If players are getting kicked with the message "Flying is not enabled on this server" which can happen with elytra, modded flight, or even floating for too long you need to allow flight in the server configuration.

1. Log in to the game panel at `gamepanel.fourseasonshosting.com` and open your server.
2. Stop the server from the **Console** page.
3. Open the **Files** page and click on `server.properties` to edit it.
4. Find the `allow-flight=` line and change its value to `true`.
5. Save the file, then start the server again.

Flight is now enabled and the built-in anti-cheat will no longer kick players for flying.
