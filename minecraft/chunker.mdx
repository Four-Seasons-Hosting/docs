---
title: "Convert a Minecraft World Between Java and Bedrock With Chunker"
description: "Use Chunker to convert a server world between Java Edition and Bedrock Edition, then upload it back."
---

[Chunker](https://chunker.app) is a free, browser-based world converter. It converts worlds between Minecraft Java Edition and Bedrock Edition, and between versions of each, including blocks, biomes, block entities, containers, items and maps. Chunker is an external tool, not run by Four Seasons Hosting.

> **Before converting:** Keep a backup of the original world. Conversion can lose or change blocks that have no equivalent in the other edition.

## Download the World From Your Server

1. Log in to the game panel at `gamepanel.fourseasonshosting.com` and open your server.
2. Stop the server from the **Console** page.
3. Open **Files** and find the world folder. On Java servers its name matches `level-name` in `server.properties` (usually `world`). On Bedrock servers it is inside the `worlds` folder.
4. Right-click the world folder, select **Archive**, then download the archive.

See [How to download a Minecraft server's world](/minecraft/download-world) for large worlds.

## Convert the World

1. Open [chunker.app](https://chunker.app). No account is needed.
2. Select **Upload archive** and choose the archive you downloaded, or drag it onto the page. Chunker detects the edition and version.
3. Choose the edition and version you want to convert to. Match your server's version.
4. Select **Convert & Download**. Advanced mode lets you change world settings and dimension handling before converting.
5. Download the converted world when Chunker finishes. If it reports an error, keep the identifier it shows and report it to the Chunker team.

## Upload the Converted World

1. Make sure your server runs the edition you converted to. Changing between Java and Bedrock changes the server software, so contact support if you need to switch.
2. Open **Files** and upload the converted archive. Use SFTP from the **Settings** page for large worlds.
3. Right-click the archive and select **Unarchive**.
4. Java: put the world folder in the main server directory. Bedrock: put it inside `worlds`.
5. Open `server.properties` and set `level-name` to the world folder name.
6. Start the server from the **Console** page.
