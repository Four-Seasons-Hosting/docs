---
title: "How to Install EssentialsX"
---

EssentialsX is a feature-rich plugin for Bukkit-based Minecraft servers. It provides a large collection of commands and adds useful server features such as player warps, kits, teleportation, and economy functionality.

EssentialsX is compatible with server software such as **Paper, Spigot, and Bukkit**.

## Install EssentialsX

1. Download the appropriate EssentialsX release from the [EssentialsX download page](https://essentialsx.net/downloads.html).
2. Sign in to the game panel at `gamepanel.fourseasonshosting.com`.
3. Stop your Minecraft server from the **Console** page.
4. Navigate to **Files**.
5. Open the `plugins` directory.
6. Upload the EssentialsX JAR file you downloaded.
7. Start your server.

Once the server finishes starting, EssentialsX will be loaded automatically.

## Customize EssentialsX

EssentialsX includes sensible default settings, so you can begin using it without making any configuration changes. If you want to customize its behavior, most of the plugin's features can be adjusted through its configuration file.

1. Stop the server.
2. Open **Files** in the game panel.
3. Navigate to `plugins/Essentials`.
4. Open `config.yml`.
5. Make the desired configuration changes.
6. Save the file.
7. Start the server again.

The changes will be applied when EssentialsX loads during the next server startup.

For a complete explanation of the available configuration options, refer to the [EssentialsX documentation](https://essentialsx.net/downloads.html).
