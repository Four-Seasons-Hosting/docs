---
title: "How to Add a Server Icon to Minecraft"
---

Minecraft allows you to add a custom image that appears beside your server in the multiplayer server list. This can be useful for branding your server or making it easier for players to identify.

Before uploading an icon, make sure it meets Minecraft's required format:

- The image must be a **PNG** file.
- The dimensions must be exactly **64 × 64 pixels**.
- The filename must be exactly `server-icon.png`.

If your image is a different size, you can use a resizing tool such as [Simple Image Resizer](https://www.simpleimageresizer.com/) to convert it to 64 × 64 pixels.

## Upload Your Server Icon

1. Log in to the game panel at `gamepanel.fourseasonshosting.com`.
2. Open the Minecraft server you want to customize.
3. Select **Files**.
4. Upload `server-icon.png` to the main server directory.
5. Make sure the file is located in the same directory as `server.properties`.
6. Restart the server from the **Console** page.

After the server starts again, Minecraft should display your custom icon in the multiplayer menu.

If the previous icon is still showing, refresh the multiplayer server list or remove and re-add the server entry to force Minecraft to update it.
