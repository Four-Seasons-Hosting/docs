---
title: "How to Locate a Minecraft Latest Log File"
---

Minecraft log files contain useful information about what is happening on your server or game client. When troubleshooting crashes, errors, mod problems, or connection issues, the `latest.log` file is often one of the first files you may be asked to provide.

## Locate latest.log on Your Minecraft Server

1. Sign in to the game panel at `gamepanel.fourseasonshosting.com`.
2. Open the server you need to troubleshoot.
3. Go to **Files**.
4. Open the `logs` directory.
5. Select `latest.log` to view the contents directly in the panel or download the file.

Previous log files are also stored in this directory. Older logs are compressed into `.gz` files and are typically organized by date.

If your server is currently running, you can also monitor its output in real time from the **Console** page.

## Locate latest.log in CurseForge

If the issue is occurring on your Minecraft client while using a CurseForge modpack, you can find the log through the modpack's installation directory.

1. Open the CurseForge launcher.
2. Select the modpack that is experiencing the problem.
3. Click the three-dot menu next to the modpack.
4. Select **Open Folder**.
5. Open the `logs` directory.
6. Locate `latest.log`.

Older client logs can be found in the same directory and are stored as compressed files.

## Locate latest.log in Modrinth

For modpacks installed through the Modrinth App:

1. Open the **Modrinth App**.
2. Right-click the modpack you are troubleshooting.
3. Select **Open Folder**.
4. Open the `logs` directory.
5. Find `latest.log`.

Previous logs will also be available in the same folder as compressed files.

## Locate latest.log Using the Minecraft Launcher

If you are using the standard Minecraft Launcher on Windows:

1. Press **Windows \+ R** to open the Run dialog.
2. Enter `%appdata%` and press **Enter**.
3. Open the `.minecraft` directory.
4. Open the `logs` folder.
5. Locate `latest.log`.

The `logs` directory also contains older log files, which are stored in compressed form.

## Share Your Log With Support

For troubleshooting, we recommend uploading your log to [mclo.gs](https://mclo.gs/). The service makes it easy to share large log files and automatically removes or masks certain sensitive information.

1. Visit [mclo.gs](https://mclo.gs/).
2. Click **Select** and choose the log file you found using the instructions above. You can also paste the contents of the log directly into the page.
3. Upload the log and select **Save**.
4. Copy the generated link from your browser.
5. Send the link to Four Seasons Hosting Support along with a description of the issue you are experiencing.

Providing the full `latest.log` gives support more information to work with and can make diagnosing the problem significantly easier.
